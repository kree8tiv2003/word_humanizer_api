Settings

Script Studio uses Claude, from Anthropic, to write your scripts. You need your own Anthropic API key. It is saved only on this computer.

  1. Go to console.anthropic.com and sign in (or create an account and add a little credit under Billing).
  2. Click Create Key, give it a name, and copy the key (it starts with sk-ant-).
  3. Paste it below and click Save.
Speech transcription (for audio stories and lyrics timing)

Script Studio can transcribe speech on this computer for free. The first time, it downloads a speech model (about 150 MB). If you have an OpenAI account, its transcription is faster and more accurate: paste an OpenAI API key here to use it instead.
